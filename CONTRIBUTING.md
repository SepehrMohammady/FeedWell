# Contributing to FeedWell

Thank you for helping make FeedWell better.

FeedWell is not open source (see [LICENSE](LICENSE)), so this repository doesn't take pull
requests. Reports and ideas are what help most.

## Report a problem

Open an issue with the problem form, or write to info@semo-lab.com. Please include:

- what you did, what you expected, and what happened instead
- the app's version (Settings, About) and your phone and Android version
- a screenshot or a short screen recording, if it shows the problem

## Suggest an idea

Open an issue with the idea form, or write to the same address. Every idea is read, with no
promise of when, or whether, it arrives in the app.

## Help with a translation

If a word or sentence reads wrong in your language, send the screen it's on, the current text
and what it should say.

## Security problems

Please don't report them in public. [SECURITY.md](SECURITY.md) explains how.

## Conduct

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
