# Security policy

## Report a problem privately

Please don't open a public issue for a security problem. Instead:

- write to info@semo-lab.com with "Security: FeedWell" in the subject, or
- use **Report a vulnerability** under this repository's Security tab, where GitHub offers it.

Say what is affected, how to reproduce it, and what someone could do with it. You'll get a
reply, and the fix arrives in an update of the app. Say so if you'd like to be credited.

## Versions that get fixes

The latest version on Google Play.

## What this covers

- The FeedWell app.

Services run by others, such as the sites whose feeds you read, Google Translate and the
public relay services FeedWell can use while you add a feed, are not SeMo Lab's to fix. Please
report problems in them to their owners.

## How FeedWell keeps your data safe

Your feeds, articles, notes and settings live in the app's private storage on your phone,
where other apps can't read them, and nothing is sent to SeMo Lab. The app fetches feeds and
articles from the sites you follow, and online translation sends an article's text to Google.
A backup file is not encrypted, so keep it somewhere you trust; it carries checksums, and a
restore refuses a file that was damaged or changed. The
[privacy policy](https://semo-lab.com/feedwell/privacy-policy/) has the details.
